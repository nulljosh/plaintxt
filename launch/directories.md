Name: Plaintxt
One-liner: A text editor that writes no editor code.
Description: Plaintxt opens and saves text, Markdown and code files in place on Mac, iPhone and iPad, using the OS's own document handling instead of rebuilding it. Line, word and character counts, light syntax colouring, no account, no sync, no tracking. $0.99 upfront on iOS, free on the web.
