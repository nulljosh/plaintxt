No accounts. No network. Free.

They don't make them like Sublime anymore

A text file is a string

Opening, saving, undo, selection, scrolling, dictation, VoiceOver: the OS already does all of that better than any JavaScript will. Plaintxt is that idea taken seriously.

Colour

Plain text stays plain

Markdown and code get colour as attributes on the same string, not a rendering layer.

Complete

Help on your own machine

Press ⌘↩ in a code file and a local Ollama model fills in at the cursor. Nothing leaves the computer.

Settings

Settings are a text file

plain.json holds the font, the model and five colours as hex. Edit, save, done.

IDE

Files, tabs, chat

On the Mac: your repo in a sidebar, tabs, format on save, and chat that sees the open file.

Build

Build, test, terminal

Run Swift and Python tests and shell commands in the output pane.

Private

No accounts, no network

Plaintxt never talks to a server. Your file is the only thing on disk.
